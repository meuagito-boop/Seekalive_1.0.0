---
name: Recomendações em prompts
description: Como tratar prompts anexados que propõem análise ou recomendações.
---

Quando um prompt é apresentado como recomendação, análise ou proposta, primeiro comparar o conteúdo com o código e as decisões já aprovadas. Apresentar o que existe, os conflitos e o caminho recomendado; pedir a decisão do usuário antes de implementar a recomendação. Uma autorização explícita separada vale somente para o escopo que ela nomear.

**Why:** Em 24/10/2026, o usuário esclareceu que um prompt enviado como recomendação deveria ser discutido antes de escolher e executar um caminho, não tratado como ordem de implementação.

**How to apply:** Ler o prompt inteiro; mapear requisitos às regras existentes; destacar especialmente conflitos de segurança e dados; explicar opções e consequências em linguagem direta; não editar até o usuário escolher.
