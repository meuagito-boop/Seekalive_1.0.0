---
name: Localização comercial
description: Regra de produto para quantas unidades físicas uma conta comercial representa.
---

Cada conta comercial do Seekalive representa no máximo uma unidade/endereço físico principal. Ainda não foi confirmado se prestadores podem publicar cidades/regiões onde atendem; a presença dessa opção no SQL de proposta não equivale a uma decisão de produto. Não expor endereço residencial automaticamente. O usuário ainda não definiu como várias contas comerciais independentes podem se agrupar sob uma marca ou rede.

**Why:** o usuário confirmou uma unidade principal por conta para evitar que o perfil comercial represente várias filiais sem modelo de identidade ou regras de compartilhamento.

**How to apply:** ao modelar contas comerciais, Seek ou Localização, preservar a relação de uma conta para no máximo um local físico principal. Não criar áreas de atendimento, hierarquia de marca/rede, compartilhar avaliações ou agregar seguidores entre contas até haver decisão explícita.
