# Aplicativo

Aplicativo público Seekalive, com o frontend atual em `front/` e a API em `back/`.

O Social, o Seek e o Shop fazem parte deste mesmo aplicativo e compartilham conta, perfil e identidade. A API atual cobre autenticação, onboarding, perfil, privacidade e relações sociais. Outros módulos ainda precisam de endpoints próprios antes de serem conectados ao backend.
